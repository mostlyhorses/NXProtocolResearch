These are sent by the lens to the camera without being polled, e.g. the lens indicates it has data and the camera reads it.

They are also sent at startup so the body knows what state things are in.

# 7001 - Focus

## Support

All lenses

&nbsp;

### Lens Status

| Byte | Function | Example |
| --- | --- | --- |
| 0   | Packet Length | 0x06 |
| 1-2 | This Code | 0x70,01 |
| 3   | Focus State | Have seen 0x03, 0x21, 0x24, ... |
| 4-5 | Focus position | 0x00,3F |

&nbsp;

### Notes

Sent in AF and MF modes.

Gets sent when focus has reached the requested position, but also at other times for no identifiable reason in AF mode.

In MF mode it gets sent when the ring stops moving.

# 7003 - Zoom / Lens Lock

## Support

Only the 20-50, and 16-50 PZ.

&nbsp;

## Lens Status

<ins>16-50 PZ</ins>

| Byte | Function | Example |
| --- | --- | --- |
| 0   | Packet Length | 0x06 |
| 1-2 | This Code | 0x70,03 |
| 3   | Status | 0x20: Zoom locked ?  <br><br/>0x03: Zoom unlocked ? |

&nbsp;

<ins>Others</ins>

| Byte | Function | Example |
| --- | --- | --- |
| 0   | Packet Length | 0x03 |
| 1-2 | This Code | 0x70,03 |
| 3   | Status | 0x20: Zoom locked ?  <br><br/>0x03: Zoom unlocked ? |
| 4-5 | Zoom Position | Zoom position in camera units |

&nbsp;

&nbsp;

## Notes

The zoom position is the same as the data in the 0x1007.5008 response (current focal length).

When unlocking, the logs in the camera also report m_bIrisStatus:0

The 16-50PZ (maybe others) has a different structure.

# 7005 - 2D/3D Change Complete

## Support

Only the 3D lens has this.

&nbsp;

## Lens Status

| Byte | Function | Example |
| --- | --- | --- |
| 0   | Packet Length | 0x04 |
| 1-2 | This Code | 0x70,05 |
| 3   | Status | 0x20: 2D mode   <br><br/>0x21: 3D Mode |

&nbsp;

## Notes

Guessing this is a status report saying the mode has switched from 2D&lt;-&gt;3D and the internal filter has finished moving. Get the 500F status, then the 7005 Status a few seconds later.
