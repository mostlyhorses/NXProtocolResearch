These appear to be commands or 'operations' the camera tells the lens to perform or requests for information from the lens.

Some of them have parameters.

Some are obviously related to features of the lens (such as OIS, aperture, focal length).

Some appear to operate on the same 50xx codes, but the data returned by the lens is varies depending on the 10xx code. So even when there are no parameters (can't be setting anything) the 10xx code requests a different aspect of the 50xx code. E.g. 1006 for 5008 has a different structure of response to the 1007 for 5008.
