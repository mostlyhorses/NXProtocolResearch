# Lens Response

The big packet describing what the lens can do.

| Byte | Function | Example |
| --- | --- | --- |
| 0   | Packet Length | 0x?? |
| 1-2 | Status | 0x20,01 |
| 3-4 | StandardVer ('st cap lens general' reports this as being 100 which matches). Guessing its the 'version' of the communication standard, or this packet? | 0x00,64 |
| 5-9 | Unknown, same for all lenses | 0x00,00,00,00,00 |
| 10-13 | m_wAdjustExecution ('st cap lens general' reports this field) .  <br>Don't know what it means though. From the name its a member variable of a class, and is probably 32-bits wide.  <br><br/>See table below for the values on different lenses. | 0x00,00,00,06 = 6 |
| Section 1: 0-3 | Number of entries in Operations section. | 0x00,00,00,0B = 11 |
| Section 1: 4 - (4+2N-1) | List of 16-bit operations supported by the lens. | 0x10,01,10,05,... |
| Section 2: 0-3 | Number of entries in the Event section. | 0x00,00,00,03 = 3 |
| Section 2: 4 - (4+2N-1) | List of 16-bit events supported by the lens. | 0x40,01... |
| Section 3: 0-3 | Number of entries in the Property section. | 0x00,00,00,09 = 9 |
| Section 3: 4 - (4+2N-1) | List of 16-bit properties supported by the lens. | 0x50,01.... |
| Section 4: 0-4 | Number of entries in the Specific Data section. | 0x00,00,00,1C = 28 |
| Section 4: 4 - (4+2N-1) | List of 16-bit SpecificData supported by the lens. | 0x60,01,... |
| Section 5:0-4 | Number of entries in the Status section. | 0x00,00,00,03 = 3 |
| Section 5: 4 - (4+2N-1) | List of 16-bit status codes supported by the lens. | 0x70,01,... |
| Section 6: Strings | Each string starts with a length byte. This includes the null terminator except for the last string where its optional (but always counted in the byte count if present).   <br><br/>String order is: "Manufacturer" or "Manufacturer + Description", Model, Versions (always xx.yy, and separated by underscores), Serial | E.g.   <br><br/>"SDIC" or "SAMSUNG??NX 50-150mm F2.8 S"  <br><br/>XL1014i2  <br><br/>01.10_02.10_03.01  <br><br/>332900001168 |
