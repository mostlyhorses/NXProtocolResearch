# Camera Request

| Byte | Function | Example | Note |
| --- | --- | --- | --- |
| 0   | Packet Length | 0x06 |     |
| 1-2 | This Code | 0x11,02 |     |
| 3   | DriveType | 0x20 / 0x24 / 0x40 |     |
| 4   | Speed | 0xFF |     |
| 5   | Value | 0x03 | Index into the 0x600E Table |

&nbsp;

&nbsp;

# Lens Response

| Bytes | Function | Note |
| --- | --- | --- |
| 0   | The packet Length | 0x04 |
| 1-2 | Status | Normal status code, e.g. 0x2001 |
| 3   | Data | Always 0x00. If it's like Op1101 then 0 means aperture is not moving, 1 means it is moving. |

&nbsp;

# Notes

When aperture is already the minimum (which is what's used for the normal operation when the shutter and DOF preview isn't pressed) this command isn't sent when the preview or shutter button is pressed.

<ins>Drive Type</ins>

NX100 & 20-50mm

- 0x24 with DOF preview press or release.
- 0x40 with shutter press or release (full, not half)

&nbsp;

NX1 & 16mm / 20-50mm / 18-55mm

- 0x40 with shutter full-press
- 0x20 with shutter release
- 0x24 with DOF preview
