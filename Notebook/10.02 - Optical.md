I think most of these things relate to how the image formed by the lens is adjusted by the camera. The exact meaning and function of most of these things is not known, so the general principle for reimplementing them is:

1.  If it appears optional leave it out.
2.  If it looks compulsory, try to identify a 'unity' transform.
3.  If can't find a unity transform, copy the settings from a similar lens.

## 0x6016 - T_NUMBER

This may be a general 'transmissivity' parameter for the lens from 0-100 (%)

Observed lenses have been in the range 82 - 94.

&nbsp;

## 0x6017 - EXT_PUPIL_POSITION

Not all lenses support it, so try leaving it out to start with.

&nbsp;

## 0x6018 - IMAGE_CIRCLE

All lenses support it, and all report the same values, so do the same.

&nbsp;

## 0x6019 - RELATIVE_ILLUMINANCE

Suspect this is used for vignetting correction.

Experiment by copying value from other lenses, or using a unity transform where I guess all elements are 2048.

Not all lenses support it, so can try leaving it out.

&nbsp;

## 0x601A - DISTORTION

This may be a distortion polynomial. Appears unity may be 10000, 0, 0 for each element.

Need to experiment to see how the images are distorted.
