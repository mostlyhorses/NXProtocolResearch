These are sent from the lens to the camera either when it is polled, or independently as a status (lens pulling LDREADY low).

When the camera polls the lens by pulsing the CLPOLL line low the lens normally responds with a 4001 code, but I have also seen it responding with 2001 codes. When this happens the lens appears to issue a status immediately afterwards with the expected 4001 code.

# 4001 - Focus

## Support

All lenses

## Data

| Byte | Function | Example | Note |
| --- | --- | --- | --- |
| 0   | Packet Length | 0x07 |     |
| 1-2 | This Code | 0x40,01 |     |
| 3-4 | Focus Position | 0x01,94 |     |
| 5   | Focus State | 0x03 / 20 / 21 / 22 / 23 | Varies. Same as Byte 3 in preceeding 7001 status. so going to say this is 'focus state' again. |
| 6   |     | 0x03 | Always 0x03? |

&nbsp;

## Notes

Sent in AF mode (not MF).

Byte 4 seems to be the same as byte 3 of the 7001 status message. When there is a 7001 followed by 4001, the numbers match.

# 4002 - iFN Button

## Support

All lenses except 30mm

## Data

| Byte | Function | Example | Note |
| --- | --- | --- | --- |
| 0   | Packet Length | 0x05 |     |
| 1-2 | This Code | 0x40,02 |     |
| 3-4 | iFN Button State | 0x01,02 | Sent when button pressed, always 0x0102 |

## Notes

Sent on iFN 'press', not on release.

&nbsp;

# 4003 - iFN Ring

## Support

All lenses except 30mm

## Data

| Byte | Function | Example | Note |
| --- | --- | --- | --- |
| 0   | Packet Length | 0x04 |     |
| 1-2 | This Code | 0x40,03 |     |
| 3   | iFN Ring movement | 0x00 / 0x01 | 0x00 = up/right; 0x01 = down/left; |

## Notes

If the iFN menu is active then this event is emitted. There must be something sent to the lens that tells it to emit this code. - YES see 0x1008.500E
