These things relate to the focal length of the lens, and how it can change.

The camera has the concept of zoom points, which are the division of the focal range into a number of steps. On prime lenses there is a single zoom point, as there is no range. On zoom lenses there are 18 zoom points (not sure if '18' is significant, or whether things will work if its more or less). Many 'specific data' have entries corresponding to each zoom point, so adjustments can be made depending on the zoom position (e.g. correcting distortion).

The 60mm macro lens uses the 'zoom points' in a special way. Although it appears to have 10 zoom points, I think it's using it to compensate for things changing at different focus positions.

Some lenses (16-50S and 50-150S) also report a finer division of each zoom point, e.g. reporting 256 intermediate steps. Enums call this ZOOM_POINT_DT.

Some lenses report an 'angular rotation' of the zoom mechanism. Inside the lens there is a potentiometer that gives a reading proportional to the angle of rotation of the zoom mechanism. This doesn't directly correspond with focal length, as the angle of rotation doesn't linearly map to the focal length (depends on the mechanics of the lens).

Some lenses can be locked, or have the zoom mechanism retracted. In this state the lens can't generate a proper picture, and the lens has to report it as 'locked' and the camera will show no picture.

| Constant | Description | Name |
| --- | --- | --- |
| Zoom | Is it a zoom lens (True) or Prime (False) | Z0  |

# Status 0x7003 - Zoom / Lens Lock

Only for lenses with \[Z3\].

This is present on the 20-50mm, 16-50 Power Zoom, and 18-200mm lenses. On the 20-50mm it is active when the zoom is adjusted wider than 20mm and the lens tube fully retracts. On the 16-50 PZ it does something similar but I'm not sure how its activated (perhaps only at poweron/off). On the 18-200 it locks the zoom in the current position so that the weight of the lens doesn't cause the mechanism to move (don't know if this comes under this 0x7003 feature or not, probably not because the lens still functions with it active).

When the zoom lock is engaged or disengaged the lens will report the status \[ZZ3\]. It doesn't wait to be polled or queried.

The 'Zoom Position' portion of the lens response can hopefully be set to an arbitrary value close to \[Z5min\].

## 0x600C - ACTUAL_FOCAL_LENGTH

This table maps each zoom point \[Z1\] to the actual lens focal length. The values are in 20ths of a mm, so 371 = 18.55mm.

&nbsp;

## 0x600D - NOMINAL_FOCAL_LENGTH

This table maps each zoom point \[Z1\] to the 'pretty' lens focal length shown to the user and corresponds with the marketing labels and is put in the image metadata. The values are in 20ths of a mm, so 360 = 18mm.
