# Support

Only the 50-150mm

&nbsp;

# Camera Request

&nbsp;

| Byte | Example | Note |
| --- | --- | --- |
| 0   | 09  | Length |
| 1-2 | 110B | This operation |
| 3-4 | 00aa | Focus |
| 5-6 | 0000 | Zoom Point Dt |
| 7   | 02  | drvType |
| 8   | 05  | speed |

&nbsp;

# Lens Response

&nbsp;

The 20-50 lens (which doesn't support it), sends back code 0x20,05

&nbsp;

# Notes

&nbsp;

Can simulate this with the telnet command 'st cap lens ctti'. This log was from a lens that doesn't support it.

```
[root@drime5 ~]# st cap lens ctti
send change_tracking_target_info(focus=170(0xaa), zoomPointDt=0(0x0), drvType=2(0x2), speed=5(0x5))
[B->L] 09 11 0b 00 aa 00 00 02 05
[L->B] 03 20 05

```
