# Camera Request

| Byte | Example | Note |
| --- | --- | --- |
| 0   | 07  | Length |
| 1-2 | 0x11,04 | This operation |
| 3   | 0x80 / 0x40 / 0x50 / 0xA0 / 0x90 | Mode |
| 4   | 0x00 |     |
| 5   | 0x00 |     |
| 6   | 0x00 |     |

&nbsp;

0x40 : Turn off

0x50 : Turn on permanently

0x80 : Turn on for duration of half shutter (if in AF mode)

0x90 : Zoom changed

0xA0 : About to take picture

# Lens Response

| Byte | Example | Note |
| --- | --- | --- |
| 0   | 04  | Length |
| 1-2 | 20,01 | Status |
| 3   | 0x00 | Complete? |

&nbsp;

# Notes

When OIS is in mode 1 (active during half-shutter hold) the camera will send 0x80, and then 0x40 when the shutter is released. If a picture is taken then is goes 0x80 -> 0xA0 -> 0x40

When OIS is in mode 2 (always active) the camera will send 0x50 to turn on permanently, then 0xA0 when taking a picture, then 0x50 again.

I guess the 0xA0 mode allows the stabilisation algorithm to do something optimised for when pictures are about to be taken.

When in Manual Focus Mode, mode 0x90 is sent when the zoom changes. On the 50-200 lens the zoom sensor is a bit jittery and jumps around +/- a step several times a second. This causes the 0x90 mode to be sent frequently and I can feel/hear a vibration in the lens.
