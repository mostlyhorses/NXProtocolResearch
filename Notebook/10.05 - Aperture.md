These things relate to the aperture of the lens and how it can be adjusted.

Internally the camera uses 16th stops, where the f-number 'f = sqrt(2) ^ (n/16)' and n is a value from 0-255, allowing f-stops from 1.0 to 250.51 to be specified.

The camera will typically sit on the smallest aperture (probably to help with autofocus), and only switch to the required one when taking a picture or DOF preview.

&nbsp;

| Constant | Description | Name |
| --- | --- | --- |
| AperturePoints | The number of elements in the table 0x600E. E.g. the number  <br>of calibrated aperture positions. | A1  |

# Op 0x100D - Request Specific Data

&nbsp;

## 0x600B - IRIS_SPEED

Every lens reports the same thing, so just repeat it.

&nbsp;

## 0x600E - WIDE_ACTUAL_F_NUMBER

This is a list of all the f-stops at the widest zoom (shortest focal length). Entries are the 'n' numbers described above.

This is calibrated per-lens.

&nbsp;

## 0x600F - OPEN_ACTUAL_F_NUMBER

This is a list of the minimum f-stop supported at each zoom point. E.g. if the lens supported f-stops 1,2,3,4,5,6,7 at the widest zoom, but this table specified 5 for the current zoom point, then the current zoom point would allow f-stops 5,6,7.

&nbsp;

## 0x6010 - NOMINAL_F_NUMBER

This table returns the 'marketing' f-stop rather than the calibrated value in 0x600E for the minimum and maximum values.

&nbsp;

## 0x6020 - WIDE_ACTUAL_FNUMBER_FI

Possibly only if \[F4\], not enough lenses have it.

Only used on the 60mm Macro lens. Not sure of the actual function, but these are very close to the 0x600E values.

&nbsp;

## 0x6021 - OPEN_ACTUAL_FNUMBER_FI

Possibly only if \[F4\], not enough lenses have it.

Only used on the 60mm Macro lens. Not sure of the actual function, but these are the same as the 0x600F values.
