The only lens without iFN is the 30mm - it still has the ring, but it's just for MF.

As noted in the Focus section the electronic ring on the lens can either be allocated to MF or iFN. I've put this as \[FF1\] in the Focus feature as the camera as the service manuals refer to this as the 'MF ring'.

# Status 0x4002 - iFN Button

If \[NN1\] then this is emitted when the iFN button is pressed (not released).

&nbsp;

# Status 0x4003 - MF/iFN Ring

If \[NN1\] then this is emitted when the ring is turned.

&nbsp;

# Op 0x1006 - Request Property Startup

&nbsp;

## 0x500D - OPERATING_METHOD_PERMISSION

Although this is tied in with Focus, I think the 500D is more related to iFN. There are fixed responses depending on whether the lens has FMO \[F1\] or not.

&nbsp;

## 0x500E - MF_RING_EVENT_PROHIBITION

See the Focus feature. It controls whether the ring is assigned to MF or iFN.

&nbsp;

# Op 0x1008 - Set Property Mode

&nbsp;

## 0x500D

This sets/clears \[NN1\]

It is emitted when the shutter is half-pressed so that iFN doesn't happen, and again when released to re-enable it.
