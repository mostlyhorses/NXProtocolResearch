Shouldn't be a surprise, but there are many messages related to focus control and feedback.

- Startup property: 0x1006, 0x5007
- Runtime property: 0x1007, 0x5007
- Set Focus Op: 0x1101
- Event: 0x4001
- Status: 0x7001   (thought I saw 0x5007 too, but can't reproduce it)

&nbsp;

# How it works

The lens focus mechanism can move between a 'far' focus position and a 'near' focus position. The position is represented by a single number, where small values are 'far' and big values are 'near'. The position number is unitless, and the ranges of values vary between lenses. When the lens moves the focus mechanism it can do it at different speeds.

Some lenses support 'full manual override' (FMO) which is where the MF ring can always tweak the focus without involvement of the camera. This is like an always on DMF which is controlled by settings on the camera. Perhaps without FMO the camera needs to receive the MF Ring event and send an op 0x1101, but with FMO the lens does it internally. When in AF mode with a lens that only has DMF the focus can be adjusted by the MF ring when the shutter is half pressed.

At startup the lens tells the camera the parameters of its focus mechanism with the messages:

- 0x100D.6004 : Focusing speed - This enumerates the different focus speeds the lens supports. It also gives a 'Noise' value that I don't know how to interpret yet.
- 0x100D.6005 : Autofocus Infinity Position - The position of infinity at each zoom level calibrated for each lens
- 0x100D.6006 : Autofocus Infinity Position Temp - Don't know how to interpret this, but appears to be an offset for the infinity and near positions.
- 0x100D.6007 : Focusing Amount - The 'useful' amount of focus range at each zoom point. The camera doesn't appear to use these.
- 0x100D.6008 : Autofocus Nearest Mechanical Limit - A mechanical limit for each zoom point, but all lenses give the same value for each point.
- 0x100D.6009 : Focus Attributes - Some constants that I don't know how to interpret yet.
- 0x100D.600A : Focus Backlash - Amount of backlash in the focus mechanism when changing direction. If given as 0 the camera assumes 10.
- 0x100D.6014 : Delta IB - Seems to be a table describing the expected sharpness of the lens at different zoom points. Possibly used by the autofocus system when working out what focus is best.
- 0x100D.601D : Delta IB F  - See above

&nbsp;

- 0x1006.5002 : Electric MF Permission - Seems to indicate if the lens supports FMO (full manual override).
- 0x1006.5003 : Focus Mode - Indicates presence and position of the AF/MF switch, and possibly whether DMF is allowed.
- 0x1006.5004 : Focus Limit - Presence and position of the focus limit switch.
- 0x1006.5007 : Focus position - Mostly unknown, but has 'Focus Range Min' and 'Focus Range Max' which are sometimes used by the autofocus system when hunting for focus.
- 0x1006.500E : MF Ring Event Prohibition
- 0x1006.5015 : Focus Range Adapt Permission
- 0x1006.5016 : Focus Range Adapt Select
- 0x1006.5017 : Focus Range Adapt Request

&nbsp;

There's also the Zoom Tracking and Tracking Targets stuff, 0x500C and op 0x110B, but I don't know what these are for or what they do. Maybe 0x500C is part of Zoom? Perhaps this is to do with keeping focus on an object when zoom is changed?

&nbsp;

At runtime the camera can request the current focus position by issuing a 0x1007.5007 command, or by polling. The lens can independently tell the camera where it is by issuing a 0x4001 event, or 0x7001 Status.

In Manual Focus mode, when the user stops moving the focus ring the lens emits a 0x7001 status.

In Auto Focus mode, the camera:

- Tells the lens to stop moving (not always, maybe it knows its still sometimes).
- Tells the lens to move to one extreme as fast as it can
- Tells the lens to move to the other extreme at a medium speed
- Tells the lens to move the other way at the same or slower speed.
- When it is confident that it has seen the best focus position, it tells the lens to move to that position as fast as it can.
- It can go back to a full wide hunt if it thinks it needs to.

&nbsp;

Lenses can also have Direct Manual Focus 'DMF'. Initially I thought only the 60 and 85mm lenses had this, but on the NX1 there is a menu option that enables it on everything. This feature lets you tweak the focus in AF mode when you turn the MF ring.

# NX1 Terminal

`st cap lens focus_pos`

lFurtherestPosition: This is the AFINF_POSITION (0x6005) for the current zoom point

lNearestPosition: This is AFINF_POSITION (0x6005) + FOCUSING_AMOUNT  (0x6007) for the current zoom point

lCurrentPosition: This is the position reported by the 7001 / 4001 / 1007.5007

ActualFNumberForAF: This is the OPEN_ACTUAL_F_NUMBER (0x600F) for the current zoom point. The widest it can be open for the current zoom.

&nbsp;

`st cap lens getrange`

When the camera is doing the wide focus hunt, these are the values it uses. This is independent of zoom level.

Focus Range Max: Element 4 from 0x5007

Focus Range Min: Element 3 from 0x5007

&nbsp;

`st cap lens af`

InfinityPosition: This is the AFINF_POSITION (0x6005) for the current zoom point

InfPositionTemp: This is the third entry for the current zoom point in AFINF_POSITION_TEMP (0x6006)

NearPosition: This is AFINF_POSITION (0x6005) + FOCUSING_AMOUNT  (0x6007) for the current zoom point

NearTempPosition: This is the first entry for the current zoom point in AFINF_POSITION_TEMP (0x6006)
