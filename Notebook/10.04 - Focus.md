These things relate to how the camera focuses the lens. See the notes [03.02 - Focus](projects/samsung%20nx%20protocol/03.02%20-%20Focus.md) for more detail.

I think electronic focus is so fundamental that this must be implemented for the camera to behave properly. If the lens only has non-electronic focus, it might be possible to come up with a configuration where the camera doesn't try to control focus, or the adapter returns something so the camera thinks its happening.

# Op 0x1101 - Set Focus

Camera issues this to set the focus position. The type is just informative for the lens, it doesn't need to do anything with it. The speed and position are all it needs to use.

The cameras response includes a flag to say if \[FF2\] == \[FF3\].

&nbsp;

This is emitted when the lens is polled by the camera.

# Status 0x5003 - Focus Mode

Only if \[F2\]

This is emitted when the AF/MF switch is changed.

&nbsp;

# Status 0x7001 - Focus

In MF mode this is emitted when the MF ring has adjusted the focus position.

In AF mode this is emitted when the focus mechanism has reached the requested position (also other random times, but not sure why).

## 0x6004 - FOCUSING_SPEED

The focus element can be moved at different speeds. This table enumerates the different options.

I don't know how the 'noise' value affects things, some lenses use values around 30-40 so start with that.

The minimum is probably 2 entries, one with speed 0, and the other with speed 255. The lens probably doesn't actually need to move at different speeds, just pretend to support it if it doesn't.
