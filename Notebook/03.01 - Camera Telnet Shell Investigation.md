# General Notes

It seems most likely that there are a number of processors all working independently, but coordinated by the one that we can get a shell on. The output of the 'st cap lens' command sometimes gets mixed up with output in the logs and other places - I'm guessing because it's coming through a log channel from one of the other processors and something is off with the synchronisation.

&nbsp;

&nbsp;

# Useful Commands

logon username is 'root' with no password.

`st cap lens spi mode 0`  -> sets slow SPI mode

`st cap lens log 5`  --> maximum log for lens

`st cap log`  --> show log
