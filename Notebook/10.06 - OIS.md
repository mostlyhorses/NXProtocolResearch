There are three OIS modes:

- Off
- Mode 1: On with half-shutter
- Mode 2: Always on

There is a difference between being 'disabled' and 'off'. When disabled the OIS module is not being used, but when not disabled the OIS may also be off if not required at the moment.

If there is an OIS switch on the lens this controls the module state, and the OIS mode selection menu will only have Mode 1 / Mode 2. If there isn't an OIS switch, the OIS mode selection menu will have Mode 1 / Mode 2 / Off.

&nbsp;

| Constant | Description | Name |
| --- | --- | --- |

| OISSwitch | Does the lens have a switch to enable/disable OIS | O2  |

# Op 0x1104 - Set OIS

The mode it supplies gives some idea of why OIS is being turned on.

&nbsp;

# Status 0x500A

Only if \[O2\]

When the switch is toggled the lens issues an 0x500A status without being polled. It simply says if OIS is now allowed to be on.

&nbsp;

# Status 0x7004

This is emitted after an Op 0x1104.

It probably indicates that it is ready.

&nbsp;

# Op 0x1006 - Request Property Startup

&nbsp;

## 0x500A - OIS_AVAILABILITY

This reports \[O2\] and \[OO1\]. There are some differences for the 60mm Macro lens, don't know what they do, so suggest using the standard values.

&nbsp;

# Op 0x1008 - Set Property Mode

## 0x500A - OIS_AVAILABILITY

If not \[O2\].

When the lens doesn't have an OIS switch, this sets \[OO1\]. It's like a virtual switch from the on-screen menu.

&nbsp;

# Op 0x100D - Request Specific Data

&nbsp;

## 0x6011 - OIS_COMPENSATION_ABILITY

All lenses with OIS return the same thing.
