The lens may issue 50xx Codes as a status (e.g. not in response to camera request or poll). I don't know how many 0x50xx codes this happens for, but the table below lists the observations.

&nbsp;

| Code | Label | Description |
| --- | --- | --- |
| 0x5003 | Focus Mode | When the AF/MF switch on the lens is toggled |
| 0x5004 | Focus Limit | When the Full/Limit switch on the lens is toggled |
| 0x500A | OIS Mode | When OIS switch on lens is toggled |
| 0x500F | 3D Mode | When 3D switch on lens is toggled |
| 0x5016 | Range Adapt Select | When Full/Custom/Set switch on lens is toggled |
| 0x5017 | Range Adapt Request | When Full/Custom/Set switch on lens is toggled |

&nbsp;

&nbsp;

# 5003 - Focus Mode

&nbsp;

| Byte | Function | Example | Note |
| --- | --- | --- | --- |
| 0   | Packet Length | 0x04 |     |
| 1-2 | This Code | 0x50,03 |     |
| 3   | Focus Mode | 0x00 / 0x01 | 0x00 = Auto; 0x01 = manual |

&nbsp;

&nbsp;

# 5004 - Focus Limit

&nbsp;

| Byte | Function | Example | Note |
| --- | --- | --- | --- |
| 0   | Packet Length | 0x04 |     |
| 1-2 | This Code | 0x50,04 |     |
| 3   | Focus Mode | 0x00 / 0x04 | 0x00 = Full; 0x04 = Limit |

&nbsp;

&nbsp;

# 0x500A - OIS Mode

&nbsp;

| Byte | Function | Example | Note |
| --- | --- | --- | --- |
| 0   | Packet Length | 0x04 |     |
| 1-2 | This Code | 0x50,03 |     |
| 3   | OIS Switch State | 0x01 / 0x02 | 0x01 = On; 0x02 = Off |

&nbsp;

# 0x500F - 3D Mode

&nbsp;

| Byte | Function | Example | Note |
| --- | --- | --- | --- |
| 0   | Packet Length | 0x04 |     |
| 1-2 | This Code | 0x50,0F |     |
| 3   | 3D Switch State | 0x00 / 0x01 | 0x00 = 2D; 0x01 = 3D |

&nbsp;

# 0x5016 - Focus Limit Custom

&nbsp;

| Byte | Function | Example | Note |

| 0   | Packet Length | 0x04 |     |
| 1-2 | This Code | 0x50,16 |     |
| 3   | Focus Limit Switch State | 0x00 / 0x01 | 0x00 = Full, 0x01 = Custom or Set |
